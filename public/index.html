🎯 Tác dụng

Công cụ giúp bạn lấy link đích cuối cùng từ các trang rút gọn link (Link4m, Layma, Site2s...). Thay vì phải:

  • Chờ đếm ngược 10–15 giây
  • Bấm qua nhiều bước quảng cáo
  • Xử lý popup, banner che màn hình

Bạn chỉ cần dán link rút gọn → bấm Bắt đầu → nhận link đích ngay.

⚙️ Cách hoạt động

Server backend của công cụ sẽ thực hiện 4 bước:

  • Bước 1: Nhận link rút gọn từ bạn.
  • Bước 2: Gửi request HTTP giả lập trình duyệt Chrome tới trang rút gọn.
  • Bước 3: Phân tích HTML trả về, tìm link đích cuối cùng.
  • Bước 4: Trả link đích về cho bạn kèm tổng thời gian xử lý.

Toàn bộ quá trình diễn ra trên server, không ảnh hưởng tới thiết bị của bạn.

⚠️ Lý do một số link không vượt được

KHÔNG VƯỢT Link4m / Gtraffic / Traffic4k

  • Các site này đã bật Cloudflare Turnstile — hệ thống chống bot yêu cầu chạy JavaScript thật, kiểm tra dấu vân tay trình duyệt và hành vi người dùng.
  • Server không thể giả lập được Turnstile nếu chỉ dùng HTTP request đơn thuần.
  • Để vượt được cần Puppeteer/Playwright (trình duyệt ảo ~500MB RAM) — vượt quá giới hạn của gói miễn phí.

VƯỢT ĐƯỢC Layma.net / Site2s.com

  • Chưa bật Cloudflare Turnstile, chỉ dùng HTML/CSS cơ bản.
  • Server có thể parse HTML và lấy link đích bình thường.
  • Tỷ lệ thành công khoảng 85–95%.

TÙY LÚC Link hết hạn / sai cú pháp

  • Link rút gọn có thời hạn — sau vài ngày có thể hết hiệu lực.
  • Link bị chủ sở hữu xóa hoặc khóa.
  • URL nhập sai định dạng (thiếu https://, dư khoảng trắng...).
📌 Lưu ý khi sử dụng
  • Nếu gặp lỗi 403 → site đã chặn bot, thử site khác.
  • Nếu gặp lỗi timeout → server đang "ngủ", đợi 30–60 giây rồi thử lại.
  • Nếu lần đầu bấm bị chậm → bình thường, lần sau sẽ nhanh hơn.
  • Không dùng công cụ để spam hoặc tấn công — chỉ dùng cá nhân.
